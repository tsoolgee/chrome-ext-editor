# 🧩 עורך תוספי כרום

עורך שיוצר ועורך תוספי כרום (Chrome Extensions) ישירות בדפדפן — בלי להתקין כלום, בלי שרת, ובלי חיבור לאינטרנט אחרי הטעינה הראשונה.

**קובץ HTML אחד. פותחים אותו בדפדפן — וזהו.**

### ▶ [לשימוש ישיר: tsoolgee.uk/chrome-ext-editor](https://tsoolgee.uk/chrome-ext-editor)

אין צורך להוריד כלום. אפשר גם להוריד את `index.html` ולהפעיל אותו מקומית — הוא עובד בדיוק אותו דבר גם בלי אינטרנט.

---

## מה זה עושה

* **עץ קבצים מלא** — יצירה, שינוי שם, שכפול, מחיקה, והעברה בין תיקיות בגרירה. לכל קובץ יש תפריט ⋯ עם כל הפעולות.
* **עורך קוד** — הדגשת תחביר ל‑JSON, JavaScript, HTML ו‑CSS, מספרי שורות, חיפוש והחלפה, וביטול/חזרה נפרדים לכל קובץ.
* **פתיחת ZIP** — גוררים תוסף קיים לתוך העורך ומתחילים לעבוד עליו.
* **הורדת ZIP** — מייצא תוסף דחוס, מוכן ל"טען פריט לא ארוז" בכרום.
* **תמונות ואייקונים** — כפתור **הוספת האייקונים המובנים** בתוך תיקיית `icons` יוצר שלושה אייקונים מוכנים (16/48/128) בלחיצה. אפשר גם להעלות בגרירה, בהדבקה (`Ctrl+V`), או להחליף קובץ קיים. קבצים בינאריים נשמרים כמו שהם.
* **בדיקת תקינות** — מוצא JSON שבור, שדות חסרים ב‑manifest, והפניות לקבצים שלא קיימים — לפני שכרום מתלונן.
* **עוזר AI מובנה** — חלונית שיחה בתוך הדף מול Gemini API. מזינים מפתח API אישי (חינם מ-[AI Studio](https://aistudio.google.com/apikey)), בוחרים מודל מתוך אלה שזמינים למפתח שלכם, וכשהתשובה מכילה קבצים יש כפתור שמחיל אותם ישירות על הפרויקט. המפתח נשמר בדפדפן בלבד.
* **שליחה לג'מיני** — כפתור שפותח כרטיסייה חדשה בג'מיני ומעתיק ללוח את הפרומפט המלא, כך שנשארת הדבקה אחת.
* **ריבוי פרויקטים** — אפשר להחזיק כמה תוספים במקביל ולעבור ביניהם, לשכפל, לשנות שם ולמחוק.
* **שמירה אוטומטית** — העבודה נשמרת בדפדפן (IndexedDB), אז רענון או סגירה לא מאבדים כלום.

---

## איך משתמשים

1. מורידים את `index.html` ופותחים אותו בדפדפן.
2. נפתח פרויקט עם כל קבצי הבסיס, ריקים. (דרך **חדש** אפשר לבחור **תבנית מלאה** — אותם קבצים עם קוד התחלתי ואייקונים מוכנים.)
3. עורכים את הקבצים.
4. לוחצים **הורדת ZIP** ומחלצים את הקובץ.
5. בכרום: `chrome://extensions` ← מפעילים **מצב מפתח** ← **טען פריט לא ארוז** ← בוחרים את התיקייה שחולצה.

אחרי כל שינוי — חוזרים ל‑`chrome://extensions` ולוחצים על כפתור הרענון בכרטיסיית התוסף.

---

## פרטיות

הכל רץ במחשב שלכם. שום קובץ לא נשלח לשום שרת, ואין בכלי שום ספרייה חיצונית. היוצא מן הכלל היחיד הוא עוזר ה-AI: אם תפעילו אותו, מה שתשלחו עובר ישירות מהדפדפן שלכם ל-Google עם המפתח שלכם. בלעדיו הכלי עובד לגמרי אופליין. גם מנוע ה‑ZIP (קריאה, כתיבה ודחיסה) כתוב מאפס בתוך הקובץ.

השמירה האוטומטית היא מקומית לדפדפן ולמחשב הזה בלבד. לגיבוי או להעברה למחשב אחר — משתמשים ב**הורדת ZIP**.
